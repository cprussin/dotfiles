* Dotfiles

My personal NixOS configurations, managed as a flake and deployed with
[[https://github.com/zhaofengli/colmena][colmena]].  You are welcome to use anything here.

** Layout

- [[./flake.nix][flake.nix]] :: Flake inputs, the colmena hive, the dev shell, and
  the installer ISOs.
- [[./cli.nix][cli.nix]] :: The ~cli~ command available in the dev shell
  (deployments, tests, etc).
- [[./config][config/]] :: The system configurations.
  - [[./config/machines][config/machines/<hostname>]] :: Machine-specific
    configuration, one directory per host.
  - [[./config/profiles][config/profiles]] :: Collections of modules packaged
    into common configuration sets.  Machine configs import profiles, which
    import modules.
  - [[./config/modules][config/modules]] :: The bulk of the configuration:
    modules for the OS, services, and applications.
  - [[./config/iot][config/iot]] :: ESPHome device configurations.
- [[./modules][modules/]] :: Custom NixOS and home-manager modules for things
  that don't exist upstream (e.g. configuring the whole system's color theme in
  one place).
- [[./lib][lib/]] :: Utility functions used throughout the codebase.
- [[./pkgs][pkgs/]] :: Custom packages and overlays.
- [[./isos][isos/]] :: Installer ISO configurations.

** Usage

Enter the dev shell (this happens automatically with direnv):

#+BEGIN_SRC bash
  nix develop
#+END_SRC

Then use ~cli~:

#+BEGIN_SRC bash
  cli deploy                    # deploy all machines
  cli deploy --on lyra          # deploy one machine
  cli test lint                 # statix
  cli test dead-code            # deadnix
  cli test format               # alejandra
  cli fix format                # auto-format the repo
  nix build .#installer         # build a NixOS installer ISO
#+END_SRC
