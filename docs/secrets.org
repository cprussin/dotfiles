* Secrets

Secrets are deployed out-of-band with colmena's ~deployment.keys~ mechanism
and never enter the nix store.

Modules declare keys with a ~keyCommand~ — an argv list executed on the
*deploying* machine at deploy time whose stdout becomes the key contents.  The
helpers in [[../lib/passwords.nix][lib/passwords.nix]] build ~keyCommand~s
that pull secrets from [[https://www.passwordstore.org/][pass]]; for example,
[[../modules/nixos/primary-user.nix][primary-user.nix]] sets the user's
hashed password from
~pass "Connor/Infrastructure/login/<user>@<host>"~.

On the target machine, keys are written to ~destDir~ (~/secrets~ in this
repo) and services reference them via ~config.deployment.keys.<name>.path~.

Keys are uploaded automatically as part of ~cli deploy~.  To upload keys
without a full deployment:

#+BEGIN_SRC bash
  cli upload-keys    # colmena upload-keys --on crux
#+END_SRC

Note that ~cli upload-keys~ targets crux by default, since crux holds the
service keys.
